Make a read-only token

A token is a password you make on GitHub for one job. This one lets the tool read your site's repository and nothing else. It cannot change anything.

Steps

  1. Sign in to GitHub. Open your profile picture, then Settings, then Developer settings, then Personal access tokens, then Fine-grained tokens.
  2. Choose Generate new token. Give it a name you will recognise, such as "My site, read only".
  3. Set the expiry as short as works for you, for example 7 days.
  4. Under repository access, choose only select repositories, and pick your site's repository. Pick no others.
  5. Under repository permissions, set Contents to read-only. Metadata is read-only already. Leave every other permission at no access.
  6. Choose Generate token. GitHub shows the token once. Copy it.
  7. Open the tool, paste the token in the box, and choose to connect. Do not paste it anywhere else.

What to know

  • The token is yours. This tool keeps it only in the open tab and sends it only to GitHub's own address, api.github.com. Closing the tab forgets it.
  • You can delete the token on GitHub at any time, in the same Fine-grained tokens list. It stops working at once.
  • Never send a token by email or chat, to anyone. No one at Sovereign Website will ask you for it.
  • GitHub changes its screens now and then. If a label differs from the one above, pick the nearest match, or ask for help.
