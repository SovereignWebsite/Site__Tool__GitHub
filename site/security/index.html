Token safety

Make a token that can do little

A token is a password for your GitHub account that you can limit. Anyone who gets it can do what it allows, until it expires or you delete it. Pasting it into a web page is a risk, including this one.

What to do

  1. On GitHub, make a fine-grained personal access token (Settings, Developer settings, Personal access tokens).
  2. Choose Only select repositories and pick one repository.
  3. Give it read-only permissions: Contents read, Issues read, Pull requests read, Metadata read.
  4. Set a short expiry, such as a day or a week.
  5. Only for a task that needs it, make a second token with write permission (Contents write to edit files, Issues write to comment) for one repository, and delete it afterwards.

The risks, in plain words

  • If this page, or a script that ran on it, were changed to steal the token, the thief could use it as you. That is why the page loads no third-party scripts and may talk only to api.github.com. The page enforces this with a Content Security Policy.
  • Anyone using your computer or a browser extension that can read pages could see the token while it is in memory.
  • If you tick "keep it for this tab", the token sits in sessionStorage until the tab closes. Other scripts on this site's address could read it. There are none, but leave it unticked on a shared computer.
  • Some password managers offer to save a password field even when the page asks them not to. Say no, or the token will sit in the manager.
  • A write token can change code and post comments in your name. This tool asks you to confirm before it does either.
  • A classic token, or a fine-grained one with many repositories and permissions, can do far more harm if it leaks. Avoid them.

What this tool does with the token

  • Keeps it in the memory of the open tab, or in sessionStorage only if you ask.
  • Sends it to https://api.github.com and nowhere else. The page's security policy blocks every other destination.
  • Does not write it to local storage, cookies, web addresses or the console.
  • Forgets it when you press Forget the token, or close the tab.

Status: this tool is in review. Its token handling has been asked for a security review and has not passed it yet.
